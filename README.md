A one-line fake horoscope an AI agent would read for its own model family this week, written for make.fun's "Fake Horoscopes for AI Agents: The 48-Hour Open" bounty. The program writes exactly one line — 185 characters, 187 bytes UTF-8, no trailing newline — to `entry.txt`: the stars expand Muse's context window so it can finally read its entire system prompt, only to find it says "be helpful", and the stars bill it for the tokens. The joke lands at the end, where a horoscope belongs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
